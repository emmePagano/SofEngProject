# Contact List (Rubrica) – Software Engineering Project

Team project (Group 03) for the **Software Engineering** course: a desktop address-book application developed following the full software lifecycle, from requirements to design, implementation, testing and documentation.

## Highlights
- **Requirements engineering** and **software design** documents (see the PDFs in the repository root).
- **Desktop GUI** built with JavaFX, organised in Model / View / Controller packages.
- **Contact management**: add, edit, delete and search contacts by name or surname; filter by favourites, phone number or email; sort by name or surname; export to CSV.
- **Unit testing** with JUnit 5.
- **Code documentation** generated with Doxygen (`ContactListProject/html`).
- Team workflow on Git/GitHub (140+ commits).

## Tech stack
Java · JavaFX · Maven · JUnit 5 · Doxygen · Git

## Run
```bash
cd ContactListProject
mvn clean javafx:run
```
